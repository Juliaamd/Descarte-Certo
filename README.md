# DescarteCerto

**Aplicação web para consulta de orientações de descarte de resíduos e localização de pontos de coleta em Goiânia – GO.**

## Sobre o projeto

O **DescarteCerto** é um projeto acadêmico desenvolvido com o propósito de facilitar o acesso a informações sobre o descarte adequado de resíduos.

A aplicação reúne orientações sobre a destinação de diferentes materiais e permite consultar pontos de coleta, contribuindo para a conscientização ambiental e o incentivo a práticas mais sustentáveis.

## Funcionalidades

- **Pesquisa de resíduos:** consulta de materiais por nome ou categoria.
- **Orientações de descarte:** informações sobre a destinação adequada de cada material.
- **Mapa interativo:** visualização de pontos de coleta em Goiânia.
- **Detalhes dos pontos:** consulta de endereço, horário de funcionamento, contato e materiais recebidos, quando disponíveis.
- **Integração entre telas:** navegação entre pesquisa, orientações, mapa e informações dos pontos de coleta.

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd DescarteCerto
   ```

3. Abra a pasta no Visual Studio Code.

4. Execute o arquivo `index.html` utilizando a extensão **Live Server**.

5. Navegue pelas funcionalidades da aplicação.

## Objetivo acadêmico

O projeto busca aplicar conhecimentos de Engenharia de Software e desenvolvimento web na criação de uma solução digital voltada à sustentabilidade.

Por meio da aplicação, são trabalhados conceitos de estruturação de páginas, estilização, programação com JavaScript, armazenamento local e integração com serviços de mapas.

## Observação

O DescarteCerto possui finalidade acadêmica e não representa um serviço oficial da Prefeitura de Goiânia. As informações sobre endereços, horários e materiais aceitos nos pontos de coleta devem ser confirmadas junto aos responsáveis pelos locais.
